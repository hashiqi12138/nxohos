# P1.6 设置界面：详细设计

> 阶段：**设计评审**。定稿后实现。
> 依赖：S1 令牌、S2 库界面（顶栏右侧空位）、P1.4 pad 编辑器（`Index.ets`）

---

## 1. 这个界面解决什么

**现状问题**：

| 问题 | 后果 |
|---|---|
| 顶栏右侧 `⚙` 位置空着 | 产品不完整，玩家找不到设置 |
| pad 布局编辑器只能长按按键进（800ms） | **没人会发现**——这是最严重的问题 |
| 没有版本信息 | 报 bug 时无法确认版本 |
| 存储占用看不到 | 玩家不知道 14.7 GB 花在哪 |
| 缓存（`.part`、旧包）无法清理 | 磁盘满了没法自救 |

**设置界面同时是 pad 编辑器的正式入口**——这是它最重要的职责。

---

## 2. 不做假开关（关键原则）

设置项必须**真的接到代码路径**，否则宁可不放。

| 想放但做不到 | 原因 | 处理 |
|---|---|---|
| 渲染分辨率 | `DM_VK_SHOT` 只是截图，没有 render scale env | **不放** |
| 帧率上限 | `fps_target` 是 **profile 里每个游戏写死的**，运行时改不了 | **不放** |
| 垂直同步 | 同上 | **不放** |
| 手柄预设（ZELDA/MARIO） | 需要多套 zone 数据 + profile 映射 | **不放**（P2.4 外接手柄时做） |
| 震动 | 需 `VIBRATE` 权限 + 真机调参 | **不放** |

**能做的**（每一项都有真实代码路径）：

| 设置项 | 接到哪 |
|---|---|
| 按键布局 | 跳转 `Index` 并 `editMode = true`（现在只能长按） |
| 按键透明度 / 大小 | 已有 `padOpacity` / `padScale`（@State，P1.4 做的） |
| 存储占用 | `treeSize(gamesDir)` + `treeSize(cacheDir)` |
| 清理缓存 | `removeTree(cacheDir + '/pack.nxpk*')` |
| 版本信息 | `app.json5` 的 versionName + 构建时间 |
| 日志位置 | 显示 `<game-root>/log.txt` 路径（玩家能复制给开发者） |

## 3. 界面结构

### 3.1 入口

**库顶栏右侧 `⚙`**（现在空着）。

```
┌──────────────────────────────────────────────────┐
│  NXOHOS                          [⚙]  [＋ 添加游戏] │
└──────────────────────────────────────────────────┘
```

### 3.2 主界面（全屏页面，非抽屉）

设置项多且有分组，用全屏页面比抽屉清楚。左侧分组导航 + 右侧内容（横屏时）；竖屏时单列。

```
┌────────────────────────────────────────────────────────────┐
│  ← 返回    设置                                             │
├──────────────┬─────────────────────────────────────────────┤
│              │                                             │
│  控制         │  按键布局                                    │
│  ▸ 画面       │  拖动调整虚拟按键的位置与大小                  │
│    数据       │                        [调整按键布局 →]      │
│    关于       │                                             │
│              │  ─────────────────────────────────          │
│              │                                             │
│              │  按键不透明度                                 │
│              │  [−]      70%      [+]                      │
│              │                                             │
│              │  按键大小                                    │
│              │  [−]     1.10×     [+]                      │
│              │                                             │
└──────────────┴─────────────────────────────────────────────┘
```

**分组**（4 组，每组 ≤ 5 项）：

| 组 | 内容 |
|---|---|
| **控制** | 按键布局入口、不透明度、大小 |
| **画面** | （暂空——等有真实可调项再加） |
| **数据** | 存储占用明细、清理缓存 |
| **关于** | 版本、构建时间、日志路径 |

**「画面」组先不显示**——没有可调项就不放空组，等 P2 有了 render scale 再加。

### 3.3 数据组

```
存储占用
  游戏数据        14.7 GB
  缓存            2.3 GB
  可用空间        32.1 GB

[清理缓存]
```

**清理缓存**要二次确认：
```
清理缓存？

将删除 2.3 GB 临时文件（未完成的导入会丢失进度）。
游戏数据和存档不受影响。

[取消]  [清理]
```

### 3.4 关于组

```
版本            1.0.0 (1000000)
构建            2026-11-16
日志            <游戏目录>/log.txt

[复制日志路径]
```

## 4. 状态与交互

| 状态 | 表现 |
|---|---|
| 计算存储中 | 数字位置显示 "计算中…"（`treeSize` 41k 文件要 1-2 秒） |
| 存储算完 | 显示真实数字 |
| 清理中 | 按钮变 "清理中…"，禁用 |
| 清理完成 | Toast "已清理 2.3 GB" |
| 版本读取失败 | 显示 "未知"，不崩 |

**焦点系统**：设置项是列表，上下键移动，左右键调步进器，Enter 激活。

## 5. 实现清单

| # | 文件 | 内容 |
|---|---|---|
| 1 | `components/SettingRow.ets` | 一行设置（标签 + 值/控件） |
| 2 | `components/SettingGroup.ets` | 分组容器（标题 + 若干行） |
| 3 | `pages/SettingsPage.ets` | 主页面（4 组、存储计算、清理） |
| 4 | `pages/LibraryPage.ets` | 顶栏加 `⚙`，跳转设置 |
| 5 | `pages/Index.ets` | 读 `editPadOnLoad` 参数，自动进编辑模式 |
| 6 | `pages/GameLibrary.ets` | `cacheSize()` / `clearCache()` 工具函数 |

### 验收标准

1. 库顶栏有 `⚙`，点击进入设置
2. 控制组能调不透明度/大小，**立即生效**（和 P1.4 编辑器共享同一份 preferences）
3. 「调整按键布局」跳转到游戏页面并自动打开编辑器
4. 数据组显示真实存储数字（游戏数据 + 缓存）
5. 清理缓存有二次确认，清理后 Toast 报告字节数
6. 关于组显示版本号
7. 全中文，无裸英文
8. 键盘/手柄可操作

## 6. 本步不做

| 不做 | 理由 |
|---|---|
| 画面设置（分辨率/帧率/同步） | 没有运行时接口，profile 是静态的 |
| 手柄布局预设 | 需要多套 zone 数据，P2.4 做 |
| 震动开关 | 需要 VIBRATE 权限 + 调参 |
| 语言切换 | 只有中文，没有第二语言 |
| 主题切换 | 只有暗色（S1 决策） |
| 账号/云同步 | 没有后端 |

---

## 7. 一个设计判断：设置和编辑器共享状态

P1.4 的编辑器（`Index.ets`）和 P1.6 的设置页都能调 `padOpacity`/`padScale`。**必须共享同一份 preferences**，否则两处数值会打架。

现在的 preferences 键：
```
'zones'    — zone 布局（JSON）
'opacity'  — 不透明度
'scale'    — 整体大小
```

设置页读写同样这三个键，`Index.ets` 启动时读。**不需要新键**。
