# P1.4 虚拟按键打磨：详细设计

> 阶段：**设计评审**。定稿后实现。
> 现状：`Index.ets` 1402 行，功能完整（摇杆、区域、编辑、持久化），但**视觉是调试级**。

---

## 1. 现状诊断（读代码得出，不是猜）

| # | 问题 | 证据 | 严重度 |
|---|---|---|---|
| **D1** | **按键按下零反馈** | `padButtons` 位掩码记录了按下状态（`Index.ets:436`），但 `drawPad()`（542 行）**从不读它**——`fillStyle` 恒为 `0.10 * op`，按下与不按完全一样 | **严重** |
| **D2** | 摇杆有反馈但很弱 | `drawStick` 旋钮 `rgba(255,255,255,0.30)`，底盘 0.08，看不出"我正在用它" | 中 |
| **D3** | 编辑器是调试面板 | 英文 `pad layout editor - drag to move, second finger to resize`、裸 `Slider`、三个英文按钮 `Save & exit` / `Reset` / `Exit (keep, unsaved)` | 高 |
| **D4** | 编辑器无预览 | 改 opacity/scale 只能看 pad 本身，看不到"游戏画面 + pad"的实际观感（因为 pad 画在 Canvas 上，背景是黑的？不——背景是 XComponent 的实时画面，这点 OK） | 低 |
| **D5** | 按键标签小且无层次 | 字号 `pr * 0.9`，白色 0.60，与圆环同权重 | 中 |
| **D6** | 无触觉反馈 | 按下无震动（`vibrator`） | 低（需权限） |

**结论：D1 是功能缺陷（用户按了不知道有没有按到），D3 是产品缺陷（设置界面对用户是英文调试面板）。**

---

## 2. 目标

| 目标 | 验收 |
|---|---|
| 按下立刻可见 | 按下按键 100ms 内出现视觉变化（填充+发光+微缩放） |
| 编辑器是产品 | 中文、分组、有数值标签、有"恢复默认"和"保存"，符合 S1 令牌 |
| 触屏/手柄都自然 | 触摸和键盘按下同一套反馈 |

**不做的**：震动反馈（需 `ohos.permission.VIBRATE` + 真机调参，独立任务）、按键布局预设（ZELDA/MARIO 等，P1.6 设置界面里做）。

## 3. 按键反馈设计（D1 + D2 + D5）

### 3.1 视觉状态

| 状态 | 填充 | 描边 | 标签 | 缩放 |
|---|---|---|---|---|
| **静置** | `rgba(255,255,255,0.10)` | `rgba(255,255,255,0.35)` 1dp | `rgba(255,255,255,0.60)` | 1.0 |
| **按下** | `rgba(236,72,153,0.42)` ← accent | `rgba(236,72,153,0.95)` 2dp | `#FFFFFF` | **0.92** |
| **按下 + 编辑模式** | 同上 + 描边虚线 | — | — | — |

**为什么用 accent 粉而不是白色**：白色加亮在亮色游戏画面上会糊掉；粉色是产品色，任何背景上都能认出"这是我按的"。与 S2 的焦点环同源。

### 3.2 按下检测

`padButtons` 已有位掩码，直接查：

```typescript
const pressed: boolean = (this.padButtons & z.bit) !== 0;
```

**不需要新状态**，`pushPad()` 之后要 `drawPad()` 重绘。查现有 `pushPad` 是否触发重绘：

- 触摸 Down 时设 `padButtons |= bit`，但**没有调 `drawPad()`**（只有 `pushPad()`）
- 所以要在 `pushPad()` 后补 `drawPad()`，或让 `pushPad()` 内部调用

### 3.3 摇杆反馈（D2）

| 状态 | 底盘 | 旋钮 |
|---|---|---|
| 静置 | `0.08` 填充 / `0.35` 描边 | `0.30` 白，r = `0.35 * pr` |
| 使用中（`lsOwner !== -1`） | `0.14` 填充 / `0.65` 描边 accent | `0.85` 白，r = `0.40 * pr` + 4dp 光晕 |

**判断"使用中"**：`this.lsOwner !== -1`（已有字段）。

## 4. 编辑器重设计（D3）

### 4.1 结构（顶部浮层，参考 S1 令牌）

```
┌──────────────────────────────────────────────────────────┐
│  按键布局                                    [完成]       │
│                                                          │
│  拖动按键移动位置 · 双指捏合调整大小                       │
│                                                          │
│  不透明度     ──────●───────  72%                        │
│  整体大小     ────●────────  1.05×                       │
│                                                          │
│  [恢复默认]                                              │
└──────────────────────────────────────────────────────────┘
```

| 元素 | 规格 |
|---|---|
| 容器 | `bg/elevated` 92% + `radius/lg`，宽 420，padding `space/5` |
| 标题 | "按键布局"，`font/title`，`text/primary` |
| 说明 | "拖动按键移动位置 · 双指捏合调整大小"，`font/caption`，`text/secondary` |
| 滑杆标签 | "不透明度" / "整体大小"，`font/label`，左对齐宽 88 |
| 滑杆数值 | `72%` / `1.05×`，`font/label`，`text/primary`，右对齐宽 56 |
| 滑杆 | `Slider`，`selectedColor` = accent，`trackColor` = `rgba(255,255,255,0.12)` |
| 主按钮 | "完成"，primary lg（保存并退出） |
| 次按钮 | "恢复默认"，secondary md |

**去掉第三个按钮**（"Exit (keep, unsaved)"）——它制造了"保存 vs 不保存"的选择焦虑，而实际上拖动位置本身就该保存。改为：**完成 = 保存**，"恢复默认" = 重置并保存。

### 4.2 交互修正

| 现在 | 改为 |
|---|---|
| Esc/Enter 保存退出 | 保留（键盘用户） |
| 三个按钮 | 两个（完成 / 恢复默认） |
| 英文 | 中文 |

## 5. 实现清单

| # | 改动 | 文件 |
|---|---|---|
| 1 | `drawPad()` 读 `padButtons`，按下态用 accent 填充 + 2dp 描边 + 0.92 缩放 | `Index.ets` |
| 2 | `drawStick()` 加"使用中"状态（accent 描边 + 更大旋钮 + 光晕） | `Index.ets` |
| 3 | 触摸 Down/Up 后调 `drawPad()`（现在只调 `pushPad()`） | `Index.ets` |
| 4 | 编辑器 UI 重写：中文、两滑杆带数值、两按钮、S1 令牌 | `Index.ets` |
| 5 | 按键标签字号提升到 `pr * 1.0`，按下时纯白 | `Index.ets` |

### 验收标准

1. 触摸按键，**100ms 内**看到粉色填充 + 描边变粗 + 轻微缩小
2. 松开立即恢复
3. 摇杆按下并拖动时，底盘描边变 accent、旋钮变大
4. 编辑器全中文，无裸英文
5. "完成"保存并退出；"恢复默认"重置所有区域+滑杆并保存
6. 键盘（方向键/Enter）触发的按下也有同样反馈
7. 游戏画面在下层可见（编辑器不遮全屏）

## 6. 本步不做

| 不做 | 理由 |
|---|---|
| 震动反馈 | 需 VIBRATE 权限 + 真机调参，独立任务 |
| 布局预设（ZELDA/MARIO 等） | P1.6 设置界面里做 |
| 按键图标（A/B/X/Y 用图形而非字母） | 现在是字母，Switch 手柄也是字母，一致 |
| 编辑模式下实时预览"游戏画面+pad" | 已经是实时的（Canvas 在 XComponent 上） |
