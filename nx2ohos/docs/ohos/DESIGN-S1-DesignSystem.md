## 1. 设计令牌（Design Tokens）

所有颜色、间距、字号、圆角、动效都走令牌。**代码里不出现裸 hex 值。**

### 1.1 颜色

#### 背景层（从深到浅，制造纵深）

| 令牌 | 值 | 用途 | 对比度检查 |
|---|---|---|---|
| `bg/base` | `#0B1220` | 应用背景（不用纯黑，避免 OLED 拖影） | — |
| `bg/elevated` | `#131C2E` | 面板、抽屉背景 | — |
| `bg/card` | `#1A2438` | 卡片默认 | — |
| `bg/cardHover` | `#22304A` | 卡片焦点/按下 | — |
| `bg/overlay` | `rgba(4,8,16,0.72)` | 模态遮罩 | — |

#### 文字

| 令牌 | 值 | 用途 | 对比度 |
|---|---|---|---|
| `text/primary` | `#F1F5F9` | 标题、游戏名 | 15.8:1 on `bg/base` ✅ |
| `text/secondary` | `#94A3B8` | 元数据（大小、版本） | 6.4:1 ✅ |
| `text/tertiary` | `#64748B` | 提示、占位 | 3.4:1（仅装饰性） |
| `text/inverse` | `#0B1220` | 主按钮上的文字 | — |

#### 语义色

| 令牌 | 值 | 用途 |
|---|---|---|
| `accent` | `#EC4899` | 焦点环、主 CTA |
| `accentHover` | `#F472B6` | 主 CTA 悬停 |
| `accentGlow` | `rgba(236,72,153,0.32)` | 焦点卡片微光 |
| `danger` | `#EF4444` | 删除按钮 |
| `dangerHover` | `#F87171` | 删除悬停 |
| `success` | `#22C55E` | "可运行"状态点 |
| `warning` | `#F59E0B` | "数据不完整" |
| `border/subtle` | `rgba(255,255,255,0.08)` | 分隔线 |
| `border/focus` | `#EC4899` | 焦点环（2dp） |

#### 占位封面底色（6 色，按 title ID 哈希）

| 索引 | 值 | 用途 |
|---|---|---|
| 0 | `#1E3A5F` | 深蓝 |
| 1 | `#3B1F4E` | 深紫 |
| 2 | `#1F3B2E` | 深绿 |
| 3 | `#3B2A1F` | 深棕 |
| 4 | `#3B1F2A` | 深红 |
| 5 | `#1F3340` | 深青 |

哈希算法：`titleId` 的字符码之和 `% 6`。保证同一游戏永远同色。

### 1.2 间距（4 的倍数）

| 令牌 | 值 |
|---|---|
| `space/1` | 4 |
| `space/2` | 8 |
| `space/3` | 12 |
| `space/4` | 16 |
| `space/5` | 24 |
| `space/6` | 32 |
| `space/7` | 48 |
| `space/8` | 64 |

### 1.3 字号

| 令牌 | 值 | 行高 | 用途 |
|---|---|---|---|
| `font/display` | 32 | 40 | 空状态标题 |
| `font/title` | 20 | 28 | 面板标题、游戏名（详情） |
| `font/body` | 16 | 24 | 游戏名（卡片）、按钮 |
| `font/label` | 14 | 20 | 元数据 |
| `font/caption` | 12 | 16 | 辅助说明 |
| `font/coverInitial` | 56 | 64 | 占位封面首字 |

**字体族**：系统默认（HarmonyOS Sans）。**不用 Orbitron**——中文不覆盖，且科技感字体在中文环境会割裂。游戏名是中文为主的场景，可读性优先。

### 1.4 圆角

| 令牌 | 值 | 用途 |
|---|---|---|
| `radius/sm` | 8 | 小按钮、标签 |
| `radius/md` | 12 | 卡片内元素 |
| `radius/lg` | 16 | 卡片、面板 |
| `radius/full` | 999 | 圆形按钮 |

### 1.5 动效

| 令牌 | 值 | 用途 |
|---|---|---|
| `motion/fast` | 120ms `easeOut` | 按下反馈、颜色变化 |
| `motion/base` | 200ms `easeOut` | 焦点移动、面板进出 |
| `motion/slow` | 320ms `easeInOut` | 页面切换 |
| `motion/scalePress` | 0.97 | 卡片按下缩放 |
| `motion/scaleFocus` | 1.06 | 焦点卡片放大 |

**缓动曲线**：`cubic-bezier(0.16, 1, 0.3, 1)`（快进慢出，有质感）。

**降级**：`prefers-reduced-motion` 时所有动效时长归零，只保留状态变化。

### 1.6 层级（z-index）

| 令牌 | 值 | 用途 |
|---|---|---|
| `z/base` | 0 | 页面内容 |
| `z/sticky` | 10 | 顶栏 |
| `z/sheet` | 20 | 底部抽屉 |
| `z/modal` | 30 | 确认对话框 |
| `z/toast` | 40 | 提示 |

## 2. 组件规范

### 2.1 GameCard（游戏卡片）

**这是产品最重要的组件。**

#### 结构

```
┌────────────────────────┐
│                        │  ← 封面区（1:1 正方形）
│                        │     有图标：铺满，object-fit: cover
│       [封面/首字]       │     无图标：哈希底色 + 首字居中
│                        │
│                        │
├────────────────────────┤  ← 分隔（1dp border/subtle）
│ 塞尔达传说 王国之泪      │  ← font/body，text/primary，最多 2 行
│ 14.7 GB · 可运行        │  ← font/label，text/secondary
└────────────────────────┘
```

#### 尺寸

| 场景 | 卡片宽 | 封面高 | 说明 |
|---|---|---|---|
| 横屏（主） | 260 | 260 | 1:1，横屏 1260 高可放 2 行 × 4 列 |
| 竖屏 | 160 | 160 | 单列横排布局时用 |

#### 状态

| 状态 | 表现 |
|---|---|
| **默认** | `bg/card`，无边框 |
| **焦点**（手柄/键盘） | 放大 1.06 + `border/focus` 2dp + `accentGlow` 外发光 8dp |
| **按下**（触摸） | 缩放 0.97，`bg/cardHover`，120ms |
| **不可用**（数据不完整） | 封面 40% 不透明，文字 `text/tertiary`，Play 禁用 |
| **启动中** | 封面覆盖 `bg/overlay`，中央显示进度环 + "正在启动" |

#### 交互

| 手势 | 行为 |
|---|---|
| 单击/轻触 | 启动游戏（焦点态下按 A 同效）|
| 长按 600ms | 打开详情抽屉 |
| 菜单键 | 打开详情抽屉 |

#### 无障碍

- `accessibilityText`：`${name}，${size}，${ready ? '可运行' : '数据不完整'}`
- `accessibilityRole`：`button`
- 焦点顺序 = 视觉顺序（左上到右下）

---

### 2.2 Button（按钮）

#### 变体

| 变体 | 背景 | 文字 | 用途 |
|---|---|---|---|
| **Primary** | `accent` | `text/inverse` | 主 CTA（启动、导入）|
| **Secondary** | 透明 + `border/subtle` 1dp | `text/primary` | 次要操作（校验、后台继续）|
| **Danger** | 透明 + `danger` 1dp | `danger` | 删除 |
| **Ghost** | 透明 | `text/secondary` | 取消、关闭 |

#### 尺寸

| 尺寸 | 高 | 左右内边距 | 字号 |
|---|---|---|---|
| `lg` | 48 | 24 | `font/body` |
| `md` | 40 | 16 | `font/label` |
| `sm` | 32 | 12 | `font/caption` |

**最小触摸目标 48×48**（`sm` 用 hitSlop 扩展到 48）。

#### 状态

| 状态 | 表现 |
|---|---|
| 默认 | 如上 |
| 按下 | 背景变亮 12%，缩放 0.97，120ms |
| 焦点 | `border/focus` 2dp 环 |
| 禁用 | 40% 不透明，不可点 |

### 2.3 ProgressBar（进度条）

用于导入。**不是转圈 spinner**——长任务需要确定性进度。

#### 结构

```
┌──────────────────────────────────────────────┐
│██████████████████████░░░░░░░░░░░░░░░░░░░░░░░░│  高 8dp，radius/full
└──────────────────────────────────────────────┘
```

- 轨道：`rgba(255,255,255,0.08)`
- 填充：`accent` 渐变到 `accentHover`（左到右）
- 高度 8dp，圆角 full
- 进度变化 200ms 缓动（不是跳变）

**不确定进度**（如"正在校验"）：填充部分左右往复滑动，周期 1.2s。

---

### 2.4 BottomSheet（底部抽屉）

用于游戏详情。

#### 结构

```
┌──────────────────────────────────────┐
│         ─────                        │  ← 拖拽把手 40×4，居中
│                                      │
│  [内容区]                             │
│                                      │
└──────────────────────────────────────┘
   ↑ 圆角 16（顶部两角）
```

- 背景 `bg/elevated`
- 遮罩 `bg/overlay`
- 从底部滑入 320ms `easeInOut`
- 最大高度 85% 屏高
- 内容可滚动

#### 关闭方式

| 方式 | 行为 |
|---|---|
| 下拉把手 | 跟手，超过 30% 高度则关闭 |
| 点遮罩 | 关闭 |
| B 键 / Esc | 关闭 |

**不能没有关闭方式**（UX 规范硬要求）。

---

### 2.5 ConfirmDialog（确认对话框）

用于删除、退出游戏。

#### 结构

```
┌────────────────────────────────────┐
│  删除 塞尔达传说 王国之泪？          │  ← font/title
│                                    │
│  将删除 14.7 GB 游戏数据。          │  ← font/body，text/secondary
│  你的存档不会受影响。                │
│                                    │
│  删除后需要重新导入才能再玩。         │  ← font/caption，text/tertiary
│                                    │
│         [取消]      [删除]          │
│           ↑默认焦点    ↑danger      │
└────────────────────────────────────┘
```

- 宽 480（横屏）/ 屏宽-32（竖屏）
- 背景 `bg/elevated`，`radius/lg`，遮罩 `bg/overlay`
- **默认焦点在"取消"**（防误触）
- 危险按钮：`danger` 文字 + `danger` 边框

#### 无障碍

- 打开时焦点移入对话框
- 关闭后焦点回到触发元素
- `accessibilityViewIsModal`: true（读屏只读对话框）

---

### 2.6 Toast（轻提示）

用于"已删除""导入失败"等一次性反馈。

- 位置：底部居中，距底 32dp（避开手势条）
- 背景 `bg/elevated`，`radius/md`，左右内边距 16，上下 12
- 文字 `font/label`
- 停留 3s 后淡出（`motion/base`）
- 同时最多 1 个（新的替换旧的）

---

### 2.7 EmptyState（空状态）

```
        [图标：空盒子，线性，48×48，text/tertiary]

              还没有游戏                       ← font/display
    导入一个游戏包（.nxpk）就可以开始玩了          ← font/body, text/secondary

         ┌────────────────────┐
         │    选择游戏包       │                ← Button primary lg
         └────────────────────┘

        查看导入指南 →                          ← font/label, accent, 可点
```

- 垂直居中
- 图标用 SVG（不用 emoji）
- 主 CTA 只有一个
- 次级链接视觉弱化

## 4. 焦点系统（手柄/键盘）

### 4.1 焦点环

```
┌─────────────────────┐  ← border/focus 2dp
│ ╭─────────────────╮ │  ← accentGlow 8dp 外发光
│ │                 │ │
│ │      卡片       │ │
│ │                 │ │
│ ╰─────────────────╯ │
└─────────────────────┘
```

- 边框 2dp `accent`
- 外发光 8dp `accentGlow`（用 shadow）
- 卡片放大 1.06（`motion/base` 200ms）
- **焦点移动时**：旧卡片缩回，新卡片放大，两者同时 200ms

### 4.2 导航规则

| 键 | 行为 |
|---|---|
| ← → | 同排左右移动，**边界不循环** |
| ↑ ↓ | 跨排移动；竖屏列表则上下移动 |
| A / Enter | 触发主操作（启动/确认）|
| B / Esc | 关闭面板/返回 |
| 菜单键 | 打开详情 |

**边界行为**：在第一个卡片按 ← 不动（不是跳到最后一个）。理由：循环会让人迷失位置。

### 4.3 焦点可见性

- 焦点必须**始终可见**（即使触摸过，焦点环也不消失）
- 打开抽屉/对话框时焦点移入
- 关闭后焦点回到触发元素

## 5. 加载与反馈

| 场景 | 反馈 |
|---|---|
| 库加载 < 200ms | 无 loading（避免闪烁）|
| 库加载 > 200ms | 骨架屏（3 个卡片轮廓，微光扫过）|
| 启动游戏 | 卡片遮罩 + 环形进度 + "正在启动" |
| 启动失败 | 卡片红边 2s + Toast 说明原因 |
| 导入中 | 顶栏细进度条（4dp），可继续浏览 |
| 删除中 | 按钮变 loading，卡片保持 |

**原则**：<200ms 不给反馈（闪烁更糟）；>1s 必须给确定性反馈（进度/步骤），不给 spinner。

## 6. 错误文案规范

**技术错误不直接暴露给用户。**

| 技术错误 | 用户文案 |
|---|---|
| `code 2300018 Transferred a partial file` | 网络中断，正在重试… |
| `code 2300028 Operation timeout` | 下载超时，下次会从断点继续 |
| `ENOSPC` | 存储空间不足，需要 14.7 GB |
| `magic != NXPK` | 这不是游戏包，请选择 .nxpk 文件 |
| `stamp mismatch` | 游戏数据需要更新 |
| 数据不完整 | 游戏数据不完整，请重新导入 |

**格式**：`[发生了什么]。[怎么办]` 两句话，不用感叹号。

### 验收标准

1. `GalleryPage` 能显示所有组件 × 所有状态
2. 所有颜色来自 `Tokens.ets`，页面代码无裸 hex
3. 焦点环在深色背景下清晰可见（对比度 ≥ 3:1）
4. 文字对比度：正文 ≥ 4.5:1，次要 ≥ 3:1
5. 触摸目标 ≥ 48×48
6. 按下反馈 120ms 内响应
7. 占位封面 6 种底色按 title ID 稳定分布
8. `prefers-reduced-motion` 时动效归零

## 8. 不做什么（明确排除）

| 不做 | 理由 |
|---|---|
| 浅色模式 | 游戏库在暗环境使用，浅色刺眼；暂不投入 |
| 自定义主题 | 产品早期，固定设计更好 |
| 动画过度（视差、粒子）| 干扰游戏启动，性能开销 |
| emoji 作为图标 | 不一致、跨设备渲染差异 |
| Orbitron 等装饰字体 | 中文不覆盖，割裂感 |
