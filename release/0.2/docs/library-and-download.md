# 游戏库与下载操作说明

## 1. 界面

打开 **NXOHOS** 就是游戏库：

- 顶部：`NXOHOS` 标题、设置、`+ 添加游戏`（从本地选择 `.nxpk` 导入）。
- 中间：已安装游戏卡片。卡片右上角状态：
  - **可运行**：`RomFS/` 与 `mods/main.patched.bin` 都在，点击直接开始游戏。
  - **不完整**：缺少上述任一目录，点击会提示"游戏数据不完整，请重新导入"，不会进入模拟器画面。
  - **已锁定**：游戏目录有 `keep` 标记，该构建不会被宿主更新覆盖。
- 底部「可下载」：列出服务器上的 `.nxpk` 与其安装状态。

## 2. 启动游戏

1. 点卡片（或用手柄方向键选中后按 A）。
2. 应用切到游戏页并立即启动，**不需要再点一次列表**。
3. 首次启动会编译/加载着色器，进入场景前的等待属于正常现象。

退出：游戏内呼出菜单选择返回游戏库。运行环境每个进程只承载一个游戏，所以返回库会结束进程，下次打开应用回到库页。

## 3. 连接下载服务器

1. 底部「可下载」栏会显示当前服务器地址（例如 `192.168.2.2:28899`）。
2. 若地址为空或需要更换，在设置中填写 PC 上提供 `.nxpk` 的 HTTP 服务地址与端口，保存后回到库页。
3. 点「刷新」拉取清单。每个条目显示包文件名与标题 ID。
4. 点「下载」：
   - 进度、速度显示在条目上；
   - 完成后自动解包到 `games/<标题ID>/`；
   - 若本地 stamp 与包相同，直接显示「√ 已安装」，不重复下载。

## 4. 常见情况

| 现象 | 原因与处理 |
|---|---|
| 下载按钮点了没反应 | 服务端包已更新（stamp 变化）时，旧状态会被重置为可下载；若仍无反应，点「刷新」再试 |
| 卡片显示"不完整" | 数据包缺少 `mods/` 或 `RomFS/`；重新下载完整包 |
| 下载中断 | 再次点「下载」会从断点继续；服务端包换了则旧分片被丢弃重下 |
| 更新后画面异常 | 确认使用的是同版本 HAP；必要时在库页删除该游戏后重新下载 |
| 空间不足 | 大型包（如《王国之泪》≈17.4 GB）需要预留约两倍空间用于解包 |

## 5. 安装 HAP（从旧版本升级）

```bash
hdc file send nxohos-0.2.0-signed.hap /data/local/tmp/nx2a-e/entry-default-signed.hap
hdc shell 'bm install -p /data/local/tmp/nx2a-e -r -w 600'
```

`-r` 表示覆盖安装。只替换运行环境，已安装的游戏数据不受影响；升级后无需重新下载游戏。
