## 验收命令

```sh
# TC0-1-1 双端构建（Windows/Linux 各执行一次，比对 SHA256）
export OHOS_SDK=/path/to/sdk/default/openharmony    # Windows 用 $env:OHOS_SDK
python probe/build_probe.py
sha256sum out/libs/arm64/libprobe.so out/bin/t_mini_nso

# TC0-1-2 安装拉起 + hilog 判定（assert_hilog 支持 --pid/--since 按
# pid+启动时间戳过滤，避免上次运行残留；hilog -r 清缓冲后可退化为纯 --must）
hdc install out/probe.hap
hdc shell hilog -r
hdc shell aa start -b ohos.probe -a ProbeAbility
sh tools/verify/run_probe.sh out/probe.hap ohos.probe ProbeAbility 40
python tools/verify/assert_hilog.py --file out/device/hilog.txt --must 'probe: started'
# 更严格（防残留串）：
#   python tools/verify/assert_hilog.py --file hilog.txt --pid <pid> --since '<time>' --must 'probe: started'

# 依赖白名单检查
llvm-readelf -d out/libs/arm64/libprobe.so
```

## 真机适配中发现并修正的 SDK 事实（G0.2 依赖回填）

| 占位假设（早期本仓） | SDK 真值（实测） |
|---|---|
| `VkSurfaceOHOSCreateInfoOHOS` + `VK_STRUCTURE_TYPE_SURFACE_OHOS_CREATE_INFO_OHOS` | **`VkSurfaceCreateInfoOHOS`**（sType = `VK_STRUCTURE_TYPE_SURFACE_CREATE_INFO_OHOS` = 1000685000，枚举非宏）；须显式 `#include <vulkan/vulkan_ohos.h>` |
| surface 用 KHR 结构 + pNext 链 | `vkCreateSurfaceOHOS(inst, &VkSurfaceCreateInfoOHOS{...})` 直接吃，`pNext` 必须 NULL、`flags` 必须 0 |
| `__system_property_get`（`<sys/system_properties.h>`） | OHOS NDK 无此头；改用 `<deviceinfo.h>` 的 `OH_GetProductModel()` / `OH_GetOSFullName()`（+ `-ldeviceinfo_ndk.z`） |
| XComponent 旧接口 `OH_NativeXComponent_GetNativeXComponent(napi_value)` | 本 SDK 只剩 `(ArkUI_NodeHandle)` 版；探针改走 `getXComponentSurfaceId()` → `OH_NativeWindow_CreateNativeWindowFromSurfaceId()`（+ `-lnative_window`） |
| BCn 16 键用 `_Static_assert(ARR[i] == ...)` 锁序 | C 中数组元素非整型常量表达式，clang 直接报错；改为 `bcn_formats.def` X-Macro 单一真源，两侧同源展开 |
